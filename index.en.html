How to interpret the result

n = spindle speed (RPM), Vc = cutting speed (m/min), D = diameter (mm). For milling or drilling, D is the tool diameter; for turning, D is the workpiece diameter at the cutting surface.

The numbers are transcribed from the supplied Spanish reference table. HSS = high-speed steel; Cermet is the table's exact tool category (not a generic synonym for carbide). Blank cells are unavailable, not zero. For drilling, the source gives only HSS values and no separate roughing/finishing speeds.

Safety: These are reference cutting speeds, not guaranteed safe settings. Check the tool maker's recommendations, workholding, machine RPM limits, coolant and setup before cutting. Feed rate is not calculated because it also depends on tool geometry and chip load or feed per revolution.
